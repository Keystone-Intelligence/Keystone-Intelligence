The Hub Model

One hub. Every agent after costs less.

One agent is useful. Nine agents on a shared hub is a different thing entirely. Keystone builds a single core hub for your business — the data layer and the integrations into the tools you already run — and every agent bolts on top of it.

That's where the economics turn. Each new agent costs less than the last, because the foundation it needs already exists. The tenth agent costs a fraction of the first. You're not paying to lay the plumbing again — you're adding intelligent automation to a hub that's already standing.

This is what separates Keystone from a one-off build. A single agent from a freelancer solves one problem and stops. A hub compounds: every agent makes the next one cheaper, and every agent makes the whole operation smarter.

Questions

What business owners ask about AI agents.

What are AI agents?

An AI agent is software that carries out a real task from start to finish, not just one step of it. It reads the incoming work, decides what to do, acts inside your systems, and hands back a finished result. Keystone runs nine of them in production across a 30-vehicle Irish waste business — handling billing, triage, accounts receivable, reconciliation, routing and customer service.

What is the difference between an AI agent and a chatbot?

A chatbot answers questions. An AI agent does the work. A chatbot might tell a customer when their bin is collected; an agent reads the email, checks the account, drafts the reply, updates the record, and flags anything unusual for a human. One talks. The other finishes the job. Under the hood, an agent uses a large language model to read and reason, then wraps it in the tools and permissions to actually act.

How many AI agents does a business need?

Fewer than you'd think to start, and more than you'd expect over time. We usually begin with the one agent that clears your biggest bottleneck, prove it in production, then add the next. The waste business grew to nine agents one at a time — each one earning its place before the next was built.

How long does it take to build a custom AI agent?

The build is a fixed-price project of roughly four weeks, from kickoff to an agent live on your data. The first agent takes the longest because it lays the foundation — the data layer and the integrations into the tools you already run. Every agent after that is faster, because the hard part already exists.

Can AI agents connect to existing systems like Xero, Salesforce, or a CRM?

Yes — that's what makes them useful. Our agents run on top of the tools you already use: Xero, Salesforce, your CRM, your job management software. They read and write where your data already lives, so nothing gets ripped out and replaced. The reconciliation agent, for instance, matches Salesforce to Xero on its own.
