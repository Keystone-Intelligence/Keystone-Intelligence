  2. Select the whole signature block inside the white box — from your name down to the tagline.
  3. Copy it (Cmd/Ctrl + C).
  4. In Gmail: Settings → See all settings → General → Signature → Create new, then paste.
  5. Set it as default for new emails and replies, and save changes at the bottom.
